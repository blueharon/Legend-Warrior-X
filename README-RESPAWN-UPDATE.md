# Respawn update

When a player's HP reaches zero, the hero immediately disappears from the arena. A three-second countdown runs, then the hero returns at the starting spawn position with 100 HP and two seconds of temporary invulnerability. The respawn deducts 15 energy. The service-worker cache was versioned so the updated game.js is fetched after deployment.

To update a GitHub Pages deployment, upload the contents of this folder to the same repository, replacing existing files, and commit the changes. Refresh the game after deployment; if the old version remains, close the installed app and clear the site's cached data.
