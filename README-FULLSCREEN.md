# Fullscreen update

This update adds a FULLSCREEN button to the top controls. Tap it to make the game arena fill the screen; tap EXIT FULLSCREEN or use the browser's exit gesture to leave fullscreen. On Android browsers that support orientation locking, it also requests landscape orientation. Browser support varies, and fullscreen is available only after a user gesture.

Replace the files in your GitHub Pages repository with the contents of this package and commit the changes. The service worker cache version has been bumped so clients can fetch the updated files.
