# Battle Audio Upgrade

This update adds synthesized looping battle music, sharper metallic sword-clash effects, and distinct synthesized ultimate cues for Kai, Lyra, Brakk, Nyx, Orin, Zeph, and Moss. No external audio files are required.

Audio starts after the player taps ENTER THE REALM because Android browsers require a user gesture before playback. The SOUND ON/OFF control toggles both music and effects. If updating an existing GitHub Pages installation, replace the updated files including `game.js` and `sw.js`, then wait for Pages to deploy. The service-worker cache version has been bumped to refresh the game files.
